# Дашборд заказов «ХэндМейд Стиль»

Статичный дашборд по выгрузке заказов интернет-магазина украшений ручной работы.
Работает без сервера и интернета.

## Как открыть

Дважды щёлкните по файлу `index.html` — он откроется в браузере (Chrome / Firefox / Edge).
Установка чего-либо не нужна.

## Что нового в версии 2

- фильтр по диапазону дат «С — По» (даты можно указывать в любом порядке);
- кнопка «Загрузить CSV» — показать свою выгрузку без правки `data.js`;
- как вариант развития на будущее — переключатель «выручка / количество»
  в топе товаров и сравнение с предыдущим периодом (см. ТЗ, п.10).

## Состав папки для передачи заказчику

Готовая копия — папка `Выдача_заказчику/`. В ней ровно восемь файлов:

| Файл | Назначение |
|---|---|
| `index.html` | дашборд (открыть двойным щелчком) |
| `styles.css`, `app.js`, `data.js` | код и данные дашборда |
| `README.md` | инструкции |
| `ТЗ_DashBoard.md` | техническое задание |
| `шаблон_заказов.xlsx` | шаблон для заполнения заказами |
| `orders-sample.csv` | пример выгрузки на 20 заказов |

Папки `.temp/` и `Case/`, а также файлы вроде `opencode.json` в выдачу не входят.

## Где заменить данные на свою выгрузку

Готовый шаблон для заполнения — файл `шаблон_заказов.xlsx`:
откройте лист «Заказы», заполните строки по образцу, сохраните его
как CSV UTF-8 с разделителем-запятой и вставьте текст в `data.js`
(шаги 7–9 описаны на листе «Инструкция» шаблона).

1. Откройте файл `data.js` в Блокноте.
2. Между обратными кавычками лежит текст выгрузки в формате CSV.
   Выделите всё содержимое между кавычками и удалите его.
3. Вставьте свою выгрузку: сохраните таблицу из Excel как CSV
   (разделитель — запятая, кодировка UTF-8), скопируйте текст файла
   и вставьте вместо удалённого.
4. Сохраните `data.js` и обновите страницу дашборда (F5).

Обязательная первая строка (заголовки колонок):

```
order_id,date,product,category,quantity,price,total
```

- `order_id` — номер заказа (число, одинаковые номера считаются одним заказом);
- `date` — дата в формате ГГГГ-ММ-ДД, например `2026-07-01`;
- `quantity`, `price`, `total` — числа; `total` = `quantity` × `price`;
- одна строка = один заказ; период в шапке дашборда определяется автоматически.

Пример выгрузки на 20 заказов — в файле `orders-sample.csv`.

## Загрузка кнопкой

Вместо правки `data.js` можно нажать кнопку «Загрузить CSV» под шапкой
и выбрать файл с выгрузкой. Файл проверяется по тем же правилам:
если колонки или значения неправильные, появится красный баннер
с описанием проблемы, а текущие данные на дашборде останутся.
Успешная загрузка заменяет данные и сбрасывает фильтр на период нового файла.

## Фильтр по датам

Под шапкой дашборда — поля «С» и «По»: они ограничивают период,
по которому считаются все блоки (карточки, топ, категории, дни).
По умолчанию показан весь период выгрузки.

- **Даты «С» и «По» можно указывать в любом порядке** (например, С = 10 июля,
  По = 1 июля) — система сама поймёт правильный диапазон, отбор не искажается;
- кнопка «Сбросить» возвращает полный период выгрузки;
- если за выбранный период заказов нет, дашборд покажет пустое состояние.

Если формат непонятен браузеру, появится красный баннер с описанием проблемы.
Если `total` не сходится с `quantity × price`, появится жёлтый баннер
с номерами проблемных заказов — расчёт продолжится по колонке `total`.
